# 메이플라이크 2D 액션 RPG: 개발 계획

## Context
빈 폴더(`C:\Users\romak\Documents\game\maplelike-rpg`)에서 새로 시작하는 프로젝트다. 목표는 메이플스토리처럼 횡스크롤 맵을 오가며 사냥하는 게임에 두 가지 요소를 섞는 것이다.
- **액션 콤보 (던파/할로우나이트)**: 연타 콤보, 커맨드 스킬, 회피/무적 프레임, 히트스톱, 패턴이 있는 보스
- **수집/파밍 (디아블로)**: 등급이 있고 랜덤 옵션이 붙는 장비, 레어 드랍을 노리는 파밍

결정 사항: **Phaser 3 + TypeScript (Vite)**, **싱글 플레이**, **그래픽은 처음에 임시 도형으로** 만들고 나중에 스프라이트로 바꾼다.

## 게임 컨셉 (핵심 루프)
마을 → 필드 맵 사냥(몬스터 리젠) → 장비 드랍·레벨업 → 더 강한 맵 → 보스 → 더 좋은 장비 파밍
- 메이플 요소: 여러 층의 발판, 로프/사다리, 아래 점프로 발판 통과, 포탈로 맵 이동, 맵마다 몬스터 리젠, 데미지 숫자, 레벨업 이펙트, 핫키 스킬
- 던파 요소: 기본공격 3타 콤보, `↓→+X` 같은 커맨드로 스킬을 쓰면 MP 할인, 공중 콤보·띄우기, 경직
- 할로우나이트 요소: 짧은 무적 대시, 공격 직전에 예고 모션을 보여주는 보스 패턴
- 디아블로 요소: 일반/매직/레어/레전더리 4등급, 접두사·접미사 랜덤 옵션, 아이템 레벨, 툴팁으로 장비 비교, 레전더리 고유 효과

## 기술 구조
```
maplelike-rpg/
  package.json, tsconfig.json, vite.config.ts, index.html
  src/
    main.ts                # Phaser.Game 설정 (Arcade Physics, 해상도 1280x720)
    scenes/
      BootScene.ts         # 임시 텍스처(도형) 생성, 데이터 로드
      GameScene.ts         # 맵 데이터를 받아 맵 하나를 구성 (마을·필드 공용)
      UIScene.ts           # HUD 오버레이: HP/MP/EXP 바, 핫키, 데미지 숫자
      InventoryScene.ts    # 인벤토리, 장비창, 툴팁
    entities/
      Player.ts            # 상태머신: idle/run/jump/climb/attack/dash/hit
      Monster.ts           # 순찰→추격→공격 AI, 넉백, 사망 시 드랍
      Boss.ts              # 패턴 테이블, 예고 모션
      DropItem.ts          # 바닥에 떨어진 아이템 (등급별 색상·빛기둥)
    systems/
      InputBuffer.ts       # 입력 기록, 커맨드 판정(↓→+X 등)
      Combat.ts            # 히트박스, 데미지 공식, 크리티컬, 히트스톱, 넉백
      Stats.ts             # 기본 스탯 + 장비 옵션 합산 → 최종 스탯
      Loot.ts              # 드랍 테이블, 등급 결정, 옵션 랜덤 생성
      Spawner.ts           # 메이플식 맵별 리젠 타이머
      Save.ts              # localStorage 저장/불러오기
    data/                  # 순수 데이터 (TS 객체)
      maps.ts, monsters.ts, skills.ts, items.ts, affixes.ts
  tests/                   # Vitest: Loot / Combat / InputBuffer / Stats
```
- 로직(데미지 공식, 루팅, 커맨드 판정, 스탯 계산)은 Phaser에 의존하지 않는 순수 함수로 분리해서 단위 테스트할 수 있게 한다.
- 맵은 처음에 `data/maps.ts`에 발판·로프·포탈 좌표로 정의한다. 나중에 필요하면 Tiled 에디터(JSON)로 옮긴다.
- 나중에 멀티플레이를 붙일 일은 없다고 보고 구조를 단순하게 유지한다.

## 마일스톤
**M0. 프로젝트 셋업**: Vite + TS + Phaser 3, Vitest, 빈 GameScene 실행

**M1. 이동 (메이플 감각)**: 좌우 이동, 점프, 더블 점프(플래시 점프), 로프/사다리 타기, 아래 점프로 발판 통과, 카메라 추적, 맵 경계

**M2. 전투 기본**: 3타 콤보(입력 버퍼), 무적 대시, 히트박스, 데미지 숫자, 히트스톱/넉백/경직, 몬스터 2종(순찰·추격), 리젠

**M3. 성장**: EXP/레벨업, HP/MP 바, 스킬 4~6개(MP·쿨다운), 핫키, 커맨드 입력 스킬(MP 할인), 공중 띄우기 콤보

**M4. 파밍**: 몬스터별 드랍 테이블, 4등급과 랜덤 옵션, 바닥 드랍 줍기, 인벤토리/장비창, 비교 툴팁, 장착하면 최종 스탯에 반영, 레전더리 고유 효과 2~3개

**M5. 월드와 보스**: 마을(NPC 상점·물약), 필드 맵 3개, 포탈 연결, 패턴 3~4개를 가진 보스 1마리, 세이브/로드

**M6. 다듬기**: 도형을 스프라이트로 교체, 효과음, 타격감 조정, 밸런스 조정

M1~M2에서 손맛이 나오는지 먼저 확인한 뒤 다음 단계로 넘어간다.

## 조작 (초안)
방향키: 이동/로프 · Alt(또는 C): 점프 · Ctrl(또는 X): 공격 · Shift: 대시 · A/S/D/F: 스킬 · I: 인벤토리 · E: 장비 · Z: 줍기 · ↑: 포탈

## 이번 작업 범위 (가장 기초 단계만)
1. 이 계획을 프로젝트 안의 `docs/PLAN.md`로 저장한다.
2. M0 셋업: `npm create`를 쓰지 않고 `package.json`, `tsconfig.json`, `vite.config.ts`, `index.html`, `src/main.ts`를 직접 작성한다. 의존성은 `phaser`, `typescript`, `vite`, `vitest`이고, `npm install` 후 `npm run dev`로 실행되는지 확인한다.
3. 가장 기초적인 플레이: `GameScene` 하나에 바닥과 발판 2~3개(도형), 네모 플레이어를 두고 좌우 이동과 점프, 카메라 추적까지만 구현한다.
4. 브라우저에서 띄워서 움직이는지 확인한 뒤 멈추고 보고한다. 다음 단계(로프, 더블 점프 등)는 사용자 확인 후 진행한다.

## 검증
- `npm run dev`로 브라우저에서 실행하고, 마일스톤마다 체크리스트로 직접 플레이해서 확인한다 (예: M1에서는 로프를 오르고 내린 뒤 아래 점프로 발판 통과).
- `npm test`(Vitest)로 루팅 확률/옵션 범위, 데미지 공식, 커맨드 판정, 스탯 합산을 단위 테스트한다.
- 필요하면 Chrome 자동화로 실행 화면을 캡처해서 확인한다.
